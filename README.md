## Nội dung thực hành

**Phần 1: Cấu hình phần cứng/phần mềm với AI (CLO13)**

1. **Tìm hiểu phần cứng (1.1)**: Dùng Grok AI tìm hiểu cách kiểm tra thông số CPU, RAM, loại ổ cứng, sau đó kiểm tra trên máy bằng Task Manager.
2. **Cài đặt Notepad++ (1.2)**: Cài đặt Python và Notepad++ theo hướng dẫn của Google Gemini, viết và chạy thành công file `Hello.py`.

**Phần 2: Giải quyết sự cố kỹ thuật với AI (CLO11)**

3. **Lỗi Wi-Fi (2.1)**: Khắc phục lỗi Wi-Fi không kết nối trên Windows 10 bằng các lệnh Command Prompt (`netsh winsock reset`, `ipconfig /release`, `ipconfig /renew`, ...) theo hướng dẫn của Grok AI.
4. **Lỗi file Python lớn (2.2)**: Notepad++ bị treo khi mở file Python dung lượng lớn. Theo gợi ý của Google Gemini, nhóm chuyển sang mở file bằng VS Code và mở thành công.

**Phần 3: Ứng dụng AI trong học tập (CLO12, CLO14)**

5. **Infographic (3.1)**: Tạo infographic "Ứng dụng AI trong công nghệ thông tin" bằng Canva AI (Magic Design), sau đó chỉnh sửa nội dung và hình ảnh.
6. **Đạo đức AI (3.2)**: Viết đoạn văn phân tích cách sử dụng Canva AI minh bạch và đạo đức theo DigComp 2.2.
